# Q5 [20 points]

Find 10 Hall of Fame players who were inducted. For each inducted player, find the earliest teammate that they appeared with. If there are multiple teammates, pick the first teammate ordered by the teammate's constructed name alphabetically. Order by the hall of fame player's constructed name alphabetically.

**File:** q5\_hof.duckdb.sql

**Details:** To find a player's teammates, find `appearances` where both players were playing for the same team in the same year.

**Hints:** You might find [Lateral Joins](https://duckdb.org/docs/sql/query_syntax/from.html#lateral-joins) in DuckDB useful. All names should be assembled as `{FIRST} ({GIVEN}) {LAST}`.

Your output should look like this:

```
hof_player_name|earliest_teammate_name|earliest_teammate_year
```

Your first row should look like this:

```
Addie (Adrian) Joss|Bill (William Henry) Bernhard|1902
```

# Q5 Solution


## Vesion 1

Find 10 Hall of Fame players who were inducted, 
for each Fame player
    find the earliest teammate that they appeared with 

```sql
SELECT h.yearID, p.nameFirst || ' ('|| p.nameGiven || ') ' || p.nameLast AS player_name, 
FROM halloffame AS h,
LATERAL (
    -- find the teammate for each player
    SELECT p.nameFirst || ' ('|| p.nameGiven || ') ' || p.nameLast AS teammate_name
    FROM appearances AS a2
    -- SEMI join to filter the teammates for the 10 hall of fame players
    WHERE EXISTS (
        SELECT a.playerID
        FROM appearances AS a
        --- ON belongs to JOIN, not EXISTS.
        ON a.yearID = a2.yearID AND a.teamID = a2.teamID AND a.lgID = a2.lgID
        --- lateral join for each year and player
        WHERE a.yearID = h.yearID AND a.playerID = h.playerID
    )
    JOIN peple as p
    ON a.playerID = p.playerID
    --- Group By is unnecessary and dangerous,You are not aggregating anything. Better: SELECT DISTINCT
    GROUP BY a.yearID, a.teamID, a.lgID
    ORDER BY teammate_name DESC
    LIMIT 1
)
JOIN peple AS p
ON h.playerID = p.playerID
-- You filter outside of LATERAL JOIN, That means the lateral subquery executes for all halloffame rows first.
WHERE h.inducted = 'Y'
ORDER BY player_name DESC
LIMIT 10;

```


## Vesion 2
Main logical model

The problem can be viewed as:
```
HallOfFame Players
        |
        |
        | for each player
        v
Find appearances where this player played
        |
        |
        v
Find other players in same:
    (yearID, teamID, lgID)
        |
        |
        v
Choose earliest year
        |
        |
        v
If multiple teammates in that year,
choose alphabetically first teammate
```


```sql
SELECT h.yearID, p.nameFirst || ' ('|| p.nameGiven || ') ' || p.nameLast AS player_name
FROM (
    SELECT * 
    FROM halloffame 
    WHERE inducted = 'Y'
    ) AS h,
LATERAL (
    -- find the teammate for each player
    SELECT p2.nameFirst || ' ('|| p2.nameGiven || ') ' || p2.nameLast AS teammate_name
    FROM appearances AS a
    -- self join to filter the teammates for the 10 hall of fame players
    --- with same year, team, league
    JOIN appearances AS a2
    ON a.yearID = a2.yearID AND a.teamID = a2.teamID AND a.lgID = a2.lgID
    JOIN people as p2
    ON a.playerID = p2.playerID
    --- lateral join for each year and player
    --- assumes: Hall of Fame induction year = year player appeared
    WHERE a2.yearID = h.yearID AND a2.playerID = h.playerID
    ORDER BY a.yearID ASC, teammate_name ASC
    LIMIT 1
)
JOIN people AS p
ON h.playerID = p.playerID
ORDER BY player_name ASC
LIMIT 10;
```

### version 3:


```sql

SELECT h.yearID, p.nameFirst || ' ('|| p.nameGiven || ') ' || p.nameLast AS player_name, t.teammate_name, t.yearID
FROM (
    SELECT * 
    FROM halloffame 
    WHERE inducted = 'Y'
    ) AS h,
LATERAL (
    -- find the teammate for each player
    SELECT p2.nameFirst || ' ('|| p2.nameGiven || ') ' || p2.nameLast AS teammate_name, teammate.yearID
    FROM appearances AS teammate
    -- self join to filter the teammates for the 10 hall of fame players
    --- with same year, team, league
    JOIN appearances AS hof
    ON teammate.yearID = hof.yearID AND teammate.teamID = hof.teamID AND teammate.lgID = hof.lgID 
    AND teammate.playerID <> hof.playerID --teammate != hall_of_fame_player
    JOIN people as p2
    ON teammate.playerID = p2.playerID
    --- lateral join for each year and player
    WHERE hof.playerID = h.playerID
    ORDER BY teammate.yearID ASC, teammate_name ASC
    LIMIT 1
) AS t
JOIN people AS p
ON h.playerID = p.playerID
ORDER BY player_name ASC
LIMIT 10;
```
